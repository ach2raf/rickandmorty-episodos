# Rick and Morty - Listado de episodios (Angular 17+)

Copia la carpeta `src/app` dentro de tu proyecto Angular (`ng new mi-proyecto`),
respetando la estructura. Si tu proyecto usa `app.ts` / `App` en lugar de
`app.component.ts` / `AppComponent`, solo añade `EpisodeListComponent` a los
`imports` del componente raíz y usa `<app-episode-list />` en su plantilla.

Después: `ng serve`
